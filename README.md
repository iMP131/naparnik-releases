# Напарник в тренировках — сборки для Android

Здесь лежат только готовые APK приложения «Напарник в тренировках» (раздел **Releases**), кода тут нет.

Приложение само проверяет новые версии и предлагает обновиться. Первую установку можно сделать
вручную: откройте последний выпуск в **Releases** и скачайте файл `.apk`.

Веб-версия: https://naparnik-app.web.app
